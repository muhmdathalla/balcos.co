# Balcos.co — Balcos Compound by Sebelas Coffee

A modern, responsive, multi-theme website for **Balcos Compound by Sebelas Coffee** located in Nologaten, Sleman, Yogyakarta.

![Balcos Preview](https://images.unsplash.com/photo-1554118811-1e0d58224f24?auto=format&fit=crop&w=1200&q=80)

## 🌟 Key Features

- 🎨 **Multi-Theme Engine**: Terracotta Signature, Midnight Dark Mode, Oat Matcha, and Cyber Twilight.
- 🕒 **24/7 Live Compound Status**: Real-time WIB clock and crowd level simulator based on Google Maps data.
- 🎵 **Web Audio Ambient Café Player**: Built-in lofi background cafe sound generator.
- 📱 **Instagram Stories Highlights**: Interactive story bubbles (`space`, `promo`, `activity`, `event`, `rent`, `meeting room`, `wazfun`).
- ☕ **Specialty Menu & Direct WhatsApp Ordering**: Instant category filtering, real-time search, dynamic shopping cart, and WhatsApp message builder (`0851-1743-9369`).
- 🏢 **VIP Meeting Room & Space Booking**: Date/time/pax selector with dynamic pricing calculation.
- 📍 **Location Hub**: Google Maps integration, Plus Code `6CF2+CR`, and delivery shortcuts (GoFood, GrabFood, ShopeeFood).

## 🚀 Live / Local Usage

Clone the repository and open `index.html` directly in your favorite web browser:

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
open index.html # On macOS
```

- **HTML5 & Vanilla JavaScript (ES6+)**
- **Bootstrap 5 & Bootstrap Icons**
- **Modern CSS3** (Custom Properties, Glassmorphism, Flexbox/Grid)
- **Web Audio API**
